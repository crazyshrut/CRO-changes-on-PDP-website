# CRO-changes-on-PDP-website

This repository contains the Conversion Rate Optimization (CRO) proposal and the enhanced product detail page (PDP) for Wellbeing Nutrition's Korean Marine Collagen Peptides.

## Files
- `index.html`: The enhanced product landing page incorporating optimized checkout, trust placement, and reduced cognitive load.
- `style.css`: Stylesheet replicating Wellbeing Nutrition's design language.
- `script.js`: Interactive functionality for pack selector, images gallery, and Consolidated AI Assistant.
- `proposal_deck.html`: Interactive web-based CRO proposal slide presentation.
- `deck_style.css`: Styling sheet for the proposal presentation.
